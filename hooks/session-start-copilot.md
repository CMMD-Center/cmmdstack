On GitHub Copilot, load cmmdstack skills by their bare names through the `skill` tool (`cmmd-mode`, `tdd`, `architect`, not `cmmdstack:cmmd-mode`); the plugin's agents keep the prefix (`cmmdstack:cmmd-agent`, `cmmdstack:comment-sicko`). Copilot lists only part of a large plugin's skills in its prompt; every cmmdstack skill a workflow names still loads by that name. `.github/copilot-instructions.md` and `~/.copilot/copilot-instructions.md` count as user instructions. Resolve every Claude tool, model, path, and built-in skill a cmmdstack skill names through `references/copilot-tools.md` in the `cmmd-mode` skill directory. cmmdstack ships no default Copilot models. A skill that dispatches on role models takes them from the user's saved cmmdstack model choices. The plugin hook reads them from the Copilot model sheet, `${COPILOT_HOME:-~/.copilot}/cmmdstack-models.md`, checks them, and adds them to the end of this block. Do not `view` the sheet. It sits outside the workspace, so reading it asks for path access. After `setup-cmmdstack` writes the sheet in this session, use the values it just wrote.

Skills that dispatch on role models: `architect`, `arena`, `cmmd-mode`, `how`, `interrogate`, `reflect`, `swarm`, `why`.
